# Immune System Cells Presentation

Teaching deck based on the report [How the Immune System Works](../).

## Materials

- [index.html](index.html) - standalone browser slide deck with keyboard navigation and print styling.
- [speaker-notes.md](speaker-notes.md) - audience objective, narrative arc, slide-by-slide talk track, appendix plan, and delivery risks.

## Delivery

- Target duration: 25-35 minutes.
- Audience: technically curious reader who has seen immune-cell vocabulary but wants the system architecture.
- Navigation: open `index.html` in a browser; use left/right arrows, page up/down, home/end, or the on-screen buttons.
- PDF export: open the deck, use browser print, and choose landscape orientation.
