# How the Immune System Works

The immune system is a layered decision system for finding danger, containing it quickly, learning its molecular signature, and remembering it without attacking self. This report explains that architecture from first principles, with special attention to four cell types: **macrophages**, **B cells**, **T cells**, and **natural killer (NK) cells**.

The report is written for a reader who wants the mechanism rather than a vocabulary list. Each chapter can be read alone, but the full arc builds from innate sensing to adaptive memory.
