# 뉴턴에서 뇌터까지 — 세미나 (2026-07-24)

물체의 운동을 기술하는 방법 — 힘, 작용, 시공간, 그리고 대칭. 물리 비전공 엔지니어 대상, 심층(~60–90분).

하나의 질문(운동을 어떻게 기술하는가)이 다섯 번 다시 쓰이는 과정을 시간순으로 따라간다: **뉴턴(힘) → 라그랑주(작용) → 특수상대성(시공간) → 일반상대성(휜 시공간) → 뇌터(대칭)**. 각 이론은 앞 이론이 남긴 질문에서 출발하고, 마지막 장에서 "보존량은 대칭의 산물"이라는 판결로 여정이 닫힌다.
