반복 공간은 어떻게 변형되는가

affine MLIR과 폴리헤드럴 모델로 루프와 iteration space가 변해가는 모습을 애니메이션으로 본다. 스케줄 행렬 θ를 바꾸거나 영역을 다시 분할하는 것만으로 — 없던 병렬성이 생기고, SIMD·페이징·파이프라인에 맞춰 타일링되고, 코어에 분배되는 과정을 단계별로 따라간다.

폴리헤드럴 모델 한 장 요약

① 반복 영역 (Domain)

루프 인덱스가 만족하는 affine 부등식들이 정의하는 정수 다면체. 각 점 = 본문의 한 실행 인스턴스.

{ (i,j) ∈ Z² | 0 ≤ i,j < N }

② 스케줄 θ (Schedule)

각 반복에 논리적 시간(timestamp)을 주는 affine 사상 = 변환행렬. 교환·스큐·타일이 모두 θ를 바꾸는 일.

θ(i,j) = M · (i,j)ᵀ

③ 접근 함수 (Access)

반복 (i,j)가 건드리는 메모리 위치를 주는 affine 사상. 재사용·지역성·페이지 거동을 정확히 계산하게 해준다.

f(i,j) = A[i][j]

④ 의존성 (Dependence)

두 반복이 같은 메모리를 쓸 때의 거리 벡터. 합법 변환은 모든 의존성을 시간상 앞으로 유지해야 한다.

δ = (Δi, Δj) ≻ 0
시각화 10편

각 페이지는 좌측 격자(iteration space) + 우측 MLIR 코드 + 스케줄 행렬 θ + 보조 패널(Gantt·벡터레인·페이징·speedup)로 구성된다. 재생 ▶으로 변환 흐름을 자동 재생하거나, 단계 칩을 눌러 한 스텝씩 살펴볼 수 있다.
